  QUICK START (5 MINUTES)
================================================================================

Step 1: Create Environment
  conda create -n ai_business_agent python=3.11
  conda activate ai_business_agent

Step 2: Install Dependencies
  pip install -r requirements.txt

Step 3: Setup API Key
  cp .env.example .env
  # Edit .env and add OPENAI_API_KEY=sk-your-key-here

Step 4: Run Tests
  python evaluation/test_calculations.py

Step 5: Start Application
  streamlit run app/streamlit_app.py

Open: http://localhost:8501

  TRY THESE QUESTIONS
================================================================================

1. "What is the total revenue?"
   → Will calculate: SUM(revenue column)

2. "Which product has the highest sales?"
   → Will find: Top product by revenue

3. "What is the profit margin?"
   → Will calculate: (profit/revenue)*100

4. "Show me monthly sales trend"
   → Will show: Line chart of monthly sales

5. "Revenue by region"
   → Will show: Bar chart by region

6. "What is the average order value?"
   → Will calculate: Mean transaction value

7. "Top 5 products"
   → Will list: Top 5 products by revenue

8. "How much profit did we make?"
   → Will calculate: Total profit (revenue - cost)

9. "Which region performed best?"
   → Will find: Highest revenue region

10. "What is our total cost?"
    → Will calculate: SUM(cost column)
